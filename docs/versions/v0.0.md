# v0.0 — Socle et laboratoire reproductible

## Objectif

Créer la base du projet et prouver la compatibilité Besu/QBFT avant de développer l'administration distante.

## À réaliser

- Lire tout le cadrage et rédiger les six ADR proposées, en justifiant les éventuels ajustements.
- Épingler les versions stables retenues : Besu, runtime Node, PostgreSQL, outils et dépendances. Documenter la matrice OS/architecture.
- Initialiser web, API, worker et modules métier ; lint, typage, build, tests et CI.
- Schéma initial Network → NodeInstance et Machine → NodeInstance, sans contrainte « une machine = un nœud ». Réserver des identifiants de services et de ports par instance.
- Modèle de jobs persistants, étapes, leases, idempotence et audit. Socle des gardes de quorum et de placement.
- Authentification OIDC, rôles côté serveur et profil de développement isolé.
- Compose : quatre validateurs, un nœud RPC non validateur, PostgreSQL et application. Données, clés, ports et volumes séparés pour chaque instance.
- Générer les clés hors Git ; conserver le genesis public et un manifeste de versions.
- Contrat témoin minimal avec valeur persistante, contrôle d'accès, événement et fonction revert ; compilation ciblant le fork EVM configuré.

## Critères de sortie

1. Une commande documentée démarre le laboratoire sur un environnement supporté.
2. Les quatre validateurs produisent des blocs ; le contrat témoin est déployé et une transaction est incluse.
3. Redémarrer Compose conserve les identités et les données.
4. Une API protégée refuse un appel sans droits.
5. Le modèle accepte plusieurs instances sur la même machine avec ports et chemins uniques.
6. Le laboratoire indique qu'il ne possède qu'un domaine de panne physique si tous les conteneurs partagent le même hôte.

## Hors périmètre

Administration SSH depuis l'interface, gouvernance interactive et sauvegardes.

Implémente uniquement v0.0 selon ce fichier et AGENTS.md. Livrer le laboratoire réel, les ADR, les migrations, les contrôles et les preuves exécutées. Arrêter le travail au critère de sortie de v0.0.
