# v0.2 — Machines, SSH/local et installation de plusieurs nœuds

## Dépendance

v0.1 validée.

## À réaliser

- Inventaire Machine : SSH ou local, adresse, utilisateur, secretRef, empreinte vérifiée, capacité, domaine de panne et racine gérée.
- Tester la connexion ; afficher les prérequis et erreurs de droits sans divulguer les secrets.
- ExecutionProvider SSH/local et playbooks fixes via ansible-runner. Inventory et extra-vars construits depuis un schéma strict, jamais importés comme code utilisateur.
- Assistant « Installer un ou plusieurs nœuds sur cette machine » : nombre, usages, dossiers, ports, CPU/RAM, stockage, version et réseau.
- Un service, une identité, des données et des ports par instance ; génération des clés sur la cible.
- Installation idempotente, démarrage, arrêt et redémarrage par instance ; actions groupées avec plan d'impact global.
- Sur un réseau existant, joindre comme non-validateur après convergence du permissioning persistant et des pairs.
- Assistant de création initiale : choisir les instances des validateurs initiaux, générer leurs clés sur place, construire un genesis unique à partir de leurs adresses publiques, le distribuer puis démarrer le réseau.
- Pour un réseau importé, adoption explicite et inspection préalable des services/chemins ; aucun écrasement automatique.
- Garde de sécurité obligatoire dès cette version pour les arrêts de validateurs, avec observations fraîches latest/pending, impact par machine et verrou réseau.
- Suppression d'un non-validateur : arrêt, retrait du peering, désinstallation ; suppression des données distincte et explicite.

## Critères de sortie

1. Depuis l'interface, déclarer une VM SSH propre et installer deux nœuds sur cette VM.
2. Les deux nœuds ont des clés, ports, services et données distincts et rejoignent la chaîne.
3. Arrêter un des deux ne stoppe pas l'autre ; réinstaller ne régénère pas les clés.
4. Le même parcours fonctionne en mode local qualifié, dans une racine dédiée.
5. Port déjà occupé, mauvais host key, disque insuffisant et chemin partagé sont refusés.
6. Une perte SSH pendant l'installation est réconciliée sans double installation.
7. Un arrêt groupé qui ferait perdre le quorum est bloqué.
8. Créer un nouveau réseau depuis l'assistant donne quatre validateurs configurés avec le même genesis et une production vérifiée.
9. Supprimer une instance ne touche ni son instance voisine ni les fichiers non gérés.

## Hors périmètre

Créer des VM chez un hébergeur, promotion par vote, terminal web et arrêt global de la chaîne. Un script local de bootstrap peut préparer l'accès SSH mais ne devient pas le seul parcours.

## Prompt

Implémente uniquement v0.2. La relation une machine / plusieurs nœuds et les deux transports SSH/local sont obligatoires. Utilise des automatisations versionnées et livre le parcours interface jusqu'aux services réellement démarrés.
